# Assets and licenses

Everything the client ships is either original to this project or listed here with its license.
There are no copyrighted characters, logos or game art, and nothing is loaded from a CDN.

## Third-party

| Asset | Where | License | Source |
|---|---|---|---|
| Press Start 2P (font, Latin subset, WOFF2) | bundled from `@fontsource/press-start-2p` 5.3.0, used via `src/styles.css` | SIL Open Font License 1.1. Copyright 2012 The Press Start 2P Project Authors (cody@zone38.net), with Reserved Font Name "Press Start 2P". | <https://fonts.google.com/specimen/Press+Start+2P>, packaged by <https://fontsource.org/fonts/press-start-2p> |

The OFL allows bundling and redistribution with the app; the font is not sold by itself or
modified. Telugu and Devanagari text uses the device's own system fonts, so no Indic font is
bundled.

## Original to this project

| Asset | Where | Notes |
|---|---|---|
| Pixel sprites (microphone, speaker, check, cross, hourglass, dots, trophy, plug) | `src/ui/sprites.ts` | Drawn for this game as character grids in the source. |
| App icons | `public/icons/*.png` | Generated by `scripts/make-icons.mjs` from a pixel grid in that file. |
| Full-screen background | `src/ui/scene.ts` | The painted scenes from `src/assets/art/backgrounds` (the library on menus, the quest scene in a game). |
| Score card | `src/share/card.ts` | Drawn procedurally at runtime. |
| Sound effects | `src/audio/sfx.ts` | Synthesised at runtime from oscillators; no samples. |
| Title music | `src/audio/sfx.ts` | An original eight-bar tune written for this game, stored as note numbers and synthesised at runtime. |
| Wizards (sage, sorceress, owl; four moods each), 12 heroes, 7 scenes | `src/assets/art/` (copied from the repo's `art/`) | Generated for this game in AICade Studio with Z-Image Turbo (Apache-2.0) and cut out with BiRefNet (MIT); every prompt, seed and post-processing step is in [`../art/credits.json`](../art/credits.json). Recompressed losslessly with oxipng (pixel-identical). Original characters only. |

## Not client assets

The spoken voices are generated by the server through Gnani Timbre and streamed to the client;
the client discloses on screen that they are AI-generated. Question packs live in `server/`.
